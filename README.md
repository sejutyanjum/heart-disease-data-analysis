# Pandas Data Analysis Using Heart Disease Dataset

## Overview
This project explores a Heart Disease dataset using Python and Pandas. It focuses on initial exploration and filtering using conditions.

## Objectives
- Explore the dataset's structure and features.
- Perform data filtering using conditions.
- Practice Python and Pandas for data analysis.

## Dataset

The dataset was obtained from Kaggle.

Dataset link: https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Project Notebook
The notebook contains the code and outputs for the project.

## How to Use
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Make sure the required dataset is available.
3. Run the cells sequentially to reproduce the analysis.

## Disclaimer
This project is for educational and data analysis purposes only. The analysis is not intended for medical diagnosis.
